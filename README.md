## Projets en vitrine

### VoxPOC

Agent vocal IA sortant. Un formulaire déclenche un appel téléphonique réel mené par une IA, avec résumé structuré généré automatiquement à la fin de la conversation.

Stack : Node.js, Express, WebSocket, Twilio Programmable Voice, Gemini Live API, React.

[Code source](https://github.com/InoussaLouqmane/voxpoc) • [Démo en ligne](https://frontend-inky-alpha-78.vercel.app)

### Projet de fin d'études

Plateforme de gestion pédagogique complète, développée dans le cadre de mon diplôme. Backend et frontend séparés, développés en parallèle.

Stack : Laravel, React.

[Backend](https://github.com/InoussaLouqmane/kata_service2) • [Frontend](https://github.com/InoussaLouqmane/Learning_Management_System)
